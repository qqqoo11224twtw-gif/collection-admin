# Recovered production baseline

These are compiled Cloudflare Worker modules and deployment metadata recovered on 2026-10-25. Original TypeScript and source maps were unavailable. This backup contains no database rows, local environment variables, or secret binding values.

Join part-000.bin through part-030.bin in numerical order into a ZIP file, verify the archive SHA-256 and each part against manifest.json, then extract into a new directory. Never deploy the recovered starter frontend over the production frontend without reviewing version differences.

OCR code on this branch is development work. Production deployment, full Telegram workflow validation, backend review integration, route provisioning and real-image accuracy evaluation are not complete. Route configuration is gated by TELEGRAM_OCR_ENABLED; leave disabled until all integration checks pass.
